L-Shell ships complete designs: each one is a whole desktop — bars and their widgets, dock, island, where panels
open, palette, typeface, radii, material, motion and how the compositor draws windows. Switching takes one click.

Open the design menu with **Super+Alt+D** (bind `l-shell msg panel-toggle design`), from the launcher ("Design"), or
pick one in **Settings → Appearance → Design**. The menu stays open, so you can try designs one after another.

| `meridian` | Meridian | One command bar at the bottom: workspaces, apps as text tabs, a search field, status. IBM Plex. |
| `atelier` | Atelier | Light paper and ink: header strip in serif, a floating shelf of apps on the left. Fraunces, DM Sans. |
| `monolith` | Monolith | Pure black, no rounding, one rail on the left; panels slide out of it. Space Grotesk, lime. |
| `halo` | Halo | Floating capsule bar with the island in its middle, a floating dock. Outfit, periwinkle. |

```toml
[design]
id = "meridian"   # one of the ids above

# How the compositor draws windows under the design (Hyprland). Every design sets its own; override here.
[design.windows]
apply           = true      # false leaves the compositor's look alone
rounding        = 6
border_size     = 1
active_border   = "3ddc97aa" # RRGGBB or RRGGBBAA
inactive_border = "2a313cff"
gaps_in         = 4
gaps_out        = 8
shadow          = false
shadow_range    = 22
shadow_offset   = "0 6"
shadow_color    = "00000057"
background      = "0b0e13ff" # behind the wallpaper (or instead of it)
```

## How a design applies

A design is a config layer that sits **under** your own config. Anything you set in your config files or in Settings
still wins, so you can adjust a design without losing it. Two rules keep switching predictable:

- If your config files define their own `[bar.*]` bars, they replace the design's bars.
- Switching from the menu or `design-set` clears earlier palette, accent, typeface and radius picks from Settings,
  because the design brings its own.

On Hyprland the window look is applied right away and written to `~/.local/state/l-shell/hyprland-design.lua`. Load
that file at the end of your `hyprland.lua` so the look survives a Hyprland reload:

```lua
pcall(dofile, os.getenv("HOME") .. "/.local/state/l-shell/hyprland-design.lua")
```

All typefaces are bundled (SIL Open Font License) under `assets/fonts/system/`.

## IPC

| Command | Effect |
|---------|--------|
| `design-list` | List the designs; `*` marks the active one. |
| `design-set <id>` | Switch to a design. |
| `design-next` | Switch to the next design. |
| `panel-toggle design` | Open or close the design menu. |
