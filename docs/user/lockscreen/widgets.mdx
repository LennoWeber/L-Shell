# Lockscreen widgets

Lockscreen widgets use the same widget types and per-type settings as [desktop widgets](/noctalia/desktop/widgets/). Layout is stored in a dedicated `[lockscreen_widgets]` section (not shared with `[desktop_widgets]` or `[lockscreen]` backdrop keys).

- Declarative config: `[lockscreen_widgets]` in `~/.config/noctalia/*.toml`
- GUI/editor overrides: `settings.toml` under your Noctalia state directory (same as desktop widgets)

```toml
[lockscreen_widgets]
enabled = true

[lockscreen_widgets.widget.clock_main]
type     = "clock"
output   = "DP-1"
cx         = 1600.0
cy         = 120.0
box_width  = 360.0
box_height = 120.0
rotation   = 0.0

[lockscreen_widgets.widget.clock_main.settings]
format = "{:%H:%M}"
```

When enabled, widgets render on each lock surface, over the same blurred and tinted wallpaper as the rest of the lock screen. L-Shell's lock screen already shows the date and a large clock at the top, like macOS; a **clock** widget on an output replaces that built-in clock there, so the screen never shows two.

Text widgets (clock, weather, media player, label, sysmon) support a per-widget `font_family` setting just like desktop widgets - empty inherits the shell font. See [Desktop widgets - Common settings](/noctalia/desktop/widgets/#common-settings).

## Edit mode

Edit mode is only available while the session is **unlocked**. The editor shows a dimmed full-screen preview with a movable **login box** preview on each monitor (one per output).

### Related IPC

For lockscreen widget edit-mode commands, see
[Surfaces → Lockscreen widgets](/noctalia/ipc/surfaces/#lockscreen-widgets).

You can also use **Settings → Security → Lock screen → Toggle Editor**.

### Controls

Same interaction model as desktop widget edit mode (move, rotate, resize, grid snap, center guides, toolbar), except the **login box** widget can only be moved (not resized or rotated). You can toggle the visibility of login boxes for individual monitors using the eye icon in the toolbar, provided that at least one login box remains visible across all monitors. Select it and open the settings inspector to adjust panel and input styling; **Reset to Defaults** at the bottom restores all login box settings. See [Desktop widgets - Edit mode](/noctalia/desktop/widgets/#edit-mode).

## Config format

The schema mirrors `[desktop_widgets]`: `enabled`, `schema_version`, optional `[lockscreen_widgets.grid]`, `widget_order`, and `[lockscreen_widgets.widget.<id>]` tables with `type`, `output`, `cx`, `cy`, `box_width`, `box_height`, `rotation`, `enabled`, and `[lockscreen_widgets.widget.<id>.settings]`.

Widget IDs generated in the editor use the `lockscreen-widget-` prefix. Login box placement uses fixed IDs `lockscreen-login-box@<output>` with `type = "login_box"` (not shown in the add-widget list).

### Login box settings

The login box is the macOS Tahoe user block: a round avatar, the display name and a glass password pill with the submit arrow inside it, low and centered. The date and the large clock sit at the top, with the current weather on the date line and a now-playing capsule under the clock. Session actions (Sleep, Restart, Shut Down, Log Out) and the keyboard layout sit as small glass circles in the bottom-right corner. Status messages (a wrong password, fingerprint and PAM prompts, Caps Lock) appear in a small chip under the pill; a wrong password shakes the pill. The editor moves the block and sets the pill width (180–360 px); positions saved for the old boxed card are reset to the default spot.

`layout` chooses how much the lock screen shows:

- `regular` (default) - avatar, name and pill, with media, weather and session actions as set below
- `compact` - the pill alone: no avatar or name, no media, weather or session actions

| Setting | Default | Range | Description |
| --- | --- | --- | --- |
| `layout` | `regular` | `compact` \| `regular` | How much the lock screen shows |
| `show_session_buttons` | `true` | bool | Regular: session actions from `[shell.session].actions` in the bottom-right corner (lock actions omitted) |
| `show_media` | `true` | bool | Regular: the now-playing capsule under the clock |
| `show_weather` | `true` | bool | Regular: the current weather on the date line |
| `show_login_button` | `true` | bool | Show the submit arrow inside the pill |
| `show_unlock_hint` | `true` | bool | Show fingerprint and PAM prompts and "Authenticating…" in the status chip; errors and Caps Lock still appear when off |
| `show_caps_lock` | `true` | bool | Show the Caps Lock glyph in the pill and a warning in the status chip |
| `show_keyboard_layout` | `true` | bool | Show the keyboard layout chip (cycles when multiple layouts are available) |
| `center_password_text` | `false` | bool | Center password dots and placeholder inside the pill |

The settings of the old boxed card (`background_color`, `background_opacity`, `background_radius`, `input_opacity`, `input_radius`) are still accepted in configs but no longer change anything.

```toml
[lockscreen_widgets.widget."lockscreen-login-box@DP-1".settings]
layout = "regular"
show_session_buttons = true
show_media = true
show_weather = true
show_unlock_hint = true
```
