These commands control shell state, logging, settings windows, the window switcher, the overview and expo, and session actions.

## General

| Action | Command | Description |
|--------|---------|-------------|
| Print status | <IpcCommand command="status" /> | Print basic shell state as JSON. |
| Show log level | <IpcCommand command="log-level-status" /> | Print the current console log level. |
| Set log level | <IpcCommand command="log-level-set debug" /> | Set the console log level for the running session. Use `debug`, `info`, `warn`, or `error`. |
| Reload config | <IpcCommand command="config-reload" /> | Reload the merged Noctalia config stack immediately. |
| Open settings | <IpcCommand command="settings-open [context]" /> | Open or focus the graphical settings window, optionally at a specific section (e.g. `bar`). |
| Open plugin settings | <IpcCommand command="settings-open-plugin noctalia/notes" /> | Open the settings window at an installed plugin's settings. The plugin must be enabled and expose settings. |
| Close settings | <IpcCommand command="settings-close" /> | Close the graphical settings window. |
| Toggle settings | <IpcCommand command="settings-toggle [context]" /> | Open or close the graphical settings window, optionally at a specific section. |
| Set layout mode | <IpcCommand command="layout-mode-set flow" /> | Switch the [layout mode](/user/layout/): `flow`, `classic`, `smart_bar`, `minimal_bar`, `island`, `edges` or `handle`. Saved like a settings change. |

Set `NOCTALIA_LOG_LEVEL` to `debug`, `info`, `warn`, or `error` before startup to choose the initial console log level. The default is `info`; the file log remains unfiltered.

## Window Switcher

Alt+Tab-style overlay with three presentations selected by `[shell.window_switcher].style`: the default `apps` is a macOS Command-Tab row of application icons on glass (no snapshots), `carousel` uses freestanding selected/near/far cards, and `compact` uses a boxed strip of equal-sized cards. Carousel cards keep stable proportions and fit snapshots inside a small themed frame, so differing window aspect ratios do not distort the layout. Captions sit below previews and the position counter sits above them. Application icons scale with the rendered preview and follow the carousel direction: bottom-left on left and selected cards, bottom-right on right cards. Close controls follow the same side at the top of left and right cards, while the selected card keeps its close control at the top-right. Moving through either style animates position, scale, opacity, and pointer-hover changes using the global animation settings. The selected card's shadow uses `[shell.shadow]`, and each close control appears only while the pointer is over its card. When the compositor supports the foreign-toplevel image-capture protocol, Noctalia takes a static snapshot of each window as the switcher opens; unsupported windows use their application icon instead. The window-switcher settings also control MRU ordering, whether captions, the counter, and application icons are shown, and which windows the list is drawn from: `show_all_outputs` picks the monitors, and `current_workspace_only` keeps the workspace shown on each of them (an open Hyprland special workspace takes over from the regular one it covers). Then wire your compositor shortcut to the IPC commands below.

| Action | Command | Description |
|--------|---------|-------------|
| Open | <IpcCommand command="window-switcher" /> | Show the switcher on the preferred monitor (pointer, keyboard focus, or first output). |
| Open from a held-modifier keybind | <IpcCommand command="window-switcher hold" /> | Same as Open, for Alt+Tab-style keybinds. If the shortcut modifier is already released when the overlay gains keyboard focus (a quick tap), the previous window is activated and the overlay closes. |
| Close | <IpcCommand command="window-switcher close" /> | Hide the overlay without changing focus. `hide` is an alias. |

Example Hyprland bind (use `hold` so a quick tap switches to the previous window):

```ini
hl.bind("ALT + TAB", hl.dsp.exec_cmd("noctalia msg window-switcher hold"))
```

While the overlay is open it takes exclusive keyboard focus on its layer surface:

- **Tab** / **Shift+Tab** - cycle selection
- **Arrow keys** - move through the active switcher style
- **Release the shortcut modifier** - focus the selected window (for example, release Alt for Alt+Tab or Super for Super+Tab)
- **Enter** - focus the selected window and close
- **Escape** - close without switching
- **Quick tap** - with `window-switcher hold`, releasing the shortcut modifier before the overlay has keyboard focus counts as the release: the previous window is activated and the overlay closes. Without `hold` (terminals, scripts, gestures), the overlay stays open until Enter, Escape, or a click
- **Pointer** - click a card to switch; click the selected card's close control to close that window

Modifier releases generated while an input method hands keyboard focus to the switcher are ignored until the physical shortcut modifier is actually released.

The switcher refreshes while the overlay stays open (new windows, closed windows, and title changes such as Discord channel switches). Selection stays on the same window when its title updates.

Snapshots are intentionally frozen for each switcher session rather than streamed. The selected window is captured first; remaining windows are captured one at a time and downsampled before display to keep the overlay responsive and memory-bounded. Compositors that do not advertise `ext_foreign_toplevel_image_capture_source_manager_v1` retain the same navigation and controls with icon-based cards.

## Overview and Expo

Two Mission-Control-style overlays on the focused monitor, over a frosted, dimmed desktop. The **overview** shows the current workspace's windows as a grid with a workspace bar on top. The **expo** shows every workspace of every monitor at once (like Hyprland's hyprexpo plugin, but built in): one miniature desktop per workspace with its wallpaper and its windows at their real positions and sizes, grouped by monitor (left to right, with a small header per monitor when there is more than one). Workspaces without windows are left out, except the one each monitor currently shows, which is outlined. Windows show a live snapshot where the compositor supports foreign-toplevel image capture, otherwise their app icon; compositors that report no window geometry get a tidy grid inside each desktop instead.

| Action | Command | Description |
|--------|---------|-------------|
| Toggle overview | <IpcCommand command="overview" /> | Open or close the overview. `toggle` is the default action. |
| Close overview | <IpcCommand command="overview close" /> | Close the overview if it is open. |
| Toggle expo | <IpcCommand command="expo" /> | Open or close the expo. `toggle` is the default action. |
| Close expo | <IpcCommand command="expo close" /> | Close the expo if it is open. |

Example Hyprland bind:

```ini
hl.bind("SUPER + O", hl.dsp.exec_cmd("l-shell-msg expo"))
# hyprland.conf: bind = SUPER, O, exec, l-shell msg expo
```

In the expo:

- **Pointer** - hover a window to highlight it and see its title; click it to focus it (the compositor switches to its workspace and monitor); click elsewhere on a desktop to switch to that workspace; click the backdrop to close
- **Arrow keys** - move between windows (and empty desktops) by position, across desktops and monitors
- **Tab** / **Shift+Tab** - next / previous desktop
- **Enter** - focus the highlighted window, or switch to the highlighted desktop
- **Escape** or **Super+O** - close

Other monitors are dimmed while the expo is open; clicking one closes it. Opening the window switcher, the overview or a panel (such as the launcher) replaces the expo, and hovering only moves the highlight once the pointer actually moves, so **Super+O** then **Enter** returns to the focused window.

The expo surface uses the layer namespace `noctalia-expo`; add it to your compositor's blur rule (see [Hyprland](/noctalia/compositor-settings/hyprland/#blur)) for the frosted backdrop.

## Session

| Action | Command | Description |
|--------|---------|-------------|
| Lock session | <IpcCommand command="session lock" /> | Lock the current session. `loginctl lock-session` uses the same path when Noctalia is running. |
| Suspend system | <IpcCommand command="session suspend" /> | Suspend without locking first. |
| Lock and suspend | <IpcCommand command="session lock-and-suspend" /> | Lock the session, then suspend once the lock is active. |
| Log out | <IpcCommand command="session logout" /> | End the graphical session (compositor-native when available). |
| Reboot | <IpcCommand command="session reboot" /> | Reboot the system. |
| Shut down | <IpcCommand command="session shutdown" /> | Shut down the system. |
